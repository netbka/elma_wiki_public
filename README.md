# ELMA Wiki - публичный сайт и демо

Сайт Петра Мамрукова о работе с изменениями в корпоративных системах: понять существующий процесс, описать запрос, подготовить решение и проверить результат.

[Открыть прототип в Sites](https://elma-wiki-peter-preview.netbka.chatgpt.site/) - пока доступен владельцу через ChatGPT.

Этот репозиторий - основное место для исходников, PR и задач публичного сайта. Внутренняя ELMA Wiki развивается отдельно в `netbka/elma_wiki`.

## Что работает

- Главная, демо, описание подхода, страница автора, связь и пояснения по запуску.
- Русский и английский интерфейс, адаптация под телефон, планшет и компьютер.
- Учебный сценарий согласования договоров: порог суммы, сравнение маршрута, три проверки и приемка в двух ролях.
- Сохранение прогресса в браузере и сброс примера.

Демо использует вымышленные данные и подготовленный сценарий. Оно не вызывает ELMA или AIWorks. Форма связи показывает предпросмотр заявки, но пока не отправляет письма. Текст обращения не сохраняется на сервере.

## Разработка

Node.js 22 и npm:

```sh
npm ci
npm run dev
```

Сборка и проверки:

```sh
npm run build
npm run test:sites
```

Статические файлы: `dist/client/`. Для Sites сборка также создает `dist/server/index.js` и `dist/.openai/hosting.json`. Готовую сборку и `node_modules` в Git не добавляем.

Маршруты: `#home`, `#demo`, `#how`, `#about`, `#contact`, `#launch`.
