# Проверка модулей и заявок

31 октября 2026. Только исходники и локальная проверка; публикация Sites не обновлялась.

- Сверена анатомия актуальной внутренней Wiki; источник и границы описаны в WORKSPACE_ADAPTATION.md.
- В Chrome пройден путь: модуль договоров -> поле приложения -> создание заявки с проверкой обязательных полей -> список с новой записью -> перезагрузка -> поиск по номеру -> карточка -> комментарий -> перезагрузка -> возврат к тому же полю. Новая заявка и комментарий сохранились, счетчик на поле увеличился.
- Проверены таблица изменений, выбор заявки на картинке и подсветка места, RU/EN, сохранение авторского текста при смене языка.
- Проверены фильтр модуля, отсутствие результатов, очистка поиска и сохранение фокуса при изменении запроса в адресе.
- При CSS-ширине 390px документ модуля и списка имеет clientWidth=scrollWidth=380px с учетом полосы прокрутки. Содержимое таблиц владеет своим горизонтальным скроллом; вторичные сведения доступны в карточке.
- Проверены browser Back/Forward с несохраненным черновиком и явная отмена через диалог: черновик восстанавливается после возврата, явный отказ очищает его. Временное состояние поднято в App, чтобы уход к описанию продукта не терял записи при недоступном хранилище.
- Семь проверок модели охватывают точную связь с каноническим полем, недопустимые места/данные, вопросы, сохранность комментариев, конфликт старой вкладки, поврежденные данные и недоступное хранилище. Четыре штатные Worker-проверки прошли. Сборка выполнена.
- Статический аудит frontend-design-premium strict: 0 findings после явного выбора native selects и согласования карты компонентов.

Физический iPhone/Safari не проверялся. Учебная среда не выполняет серверные операции или совместные транзакции; этапы подготовленных записей не изображают реальную работу ИИ.
