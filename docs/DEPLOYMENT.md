# Развертывание

## Текущий прототип

Адрес: https://elma-wiki-peter-preview.netbka.chatgpt.site/

Доступ в Sites остается только у владельца. Перенос исходников в публичный GitHub не меняет доступ к этому адресу и не подключает автоматический деплой.

## Обычный статический хостинг

1. Установить Node.js 22 и зависимости командой `npm ci`.
2. Выполнить `npm run build` и `npm run test:sites`.
3. Загрузить содержимое `dist/client/` в корень сайта на выбранном хостинге.
4. Подключить домен и HTTPS.
5. Проверить переходы, русский и английский языки, сохранение демо и загрузку с телефона.

Маршруты используют hash, поэтому для шести страниц не требуется серверный роутинг. Отдельная база для нынешнего демо не нужна: оно хранит прогресс в браузере посетителя. Для самостоятельной статической публикации Worker из `dist/server/` не нужен.

Проверку доступности из российских домашних и мобильных сетей выполнить перед запуском. Выбор провайдера, тариф и настройка домена остаются отдельной задачей. Здесь не приводятся обещания доступности или непроверенные цены.

## Обновление существующего Sites

1. Взять нужный проверенный commit из этого репозитория.
2. Открыть существующий проект Sites через его штатный процесс работы с исходниками.
3. Перенести изменения, сохранив текущий `.openai/hosting.json` и идентификатор проекта.
4. Собрать, проверить, синхронизировать снимок исходников и опубликовать его штатными средствами Sites.
5. Проверить результат публикации. Смена аудитории - отдельное действие владельца.

Не создавать второй сайт при обычном обновлении. Не сохранять токены Git, доступ к почте или другие секреты в исходниках.

## Что еще требуется

- Для реальной формы: серверный обработчик, защита от повторов и спама, доставка письма владельцу, понятные состояния успеха и ошибки, согласованный текст обработки данных.
- Для продолжения демо на другом устройстве: отдельная авторизация и хранение изолированных данных посетителей, срок хранения, сброс и удаление.
- Подключение реальных ELMA и AIWorks не входит в этот учебный сайт.
